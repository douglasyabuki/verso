# Source register

Accessed **2026-10-23**. All pages below were opened and read, not used only through search snippets. Dates below are displayed update dates where available; undated does not mean current. These sources support advice, not causal hiring claims. Reference labels used in other files identify the supporting page.

## Evidence classes

- **Technical constraint:** documented behavior/limit of a named product, version/settings permitting. Applies only to that product/context; reverify when consequential.
- **Professional recommendation:** career-advising practice, not scientific proof of hiring outcomes.
- **Context convention:** market, institution, career stage, or application expectation; verify scope.
- **Design default:** Resume Pro's practical starting choice, explicitly adjustable and not a sourced standard.

## Applying the evidence

Keep substantial advice in the focused references, not copied guides. Recommendations without a source label are practical editorial/design judgments governed by the factual constraints. No source here proves an optimal font, a universal page count, recruiter reading time, hiring probability, or ATS pass rate. Explain consequential conflicts using markets.md. For inaccessible future sources, record the failed page, suitable primary replacement, and changed support; never cite an unread source as verified.
